# מדבקות — אפקון טכנולוגיות · גרסה 6.4

## התקנה
העלה את שלושת הקבצים לשורש המאגר, זה לצד זה:

```
avieotok/tavit/
├── index.html
├── sw.js
└── manifest.webmanifest
```

`sw.js` חייב לשבת בשורש, אחרת מצב האופליין לא יעבוד.

## בעדכון גרסה עתידי
עדכן את המספר בשורה הראשונה של `sw.js`:
```js
const CACHE = 'afkon-labels-v6.4';
```

## גיבוי והעברה בין מכשירים
1. במכשיר המקור: אודות ← "⬇ ייצא גיבוי".
2. שלח את הקובץ **כמסמך מצורף** (Document), לא כטקסט מודבק.
3. במכשיר היעד: אודות ← "⬆ שחזר מגיבוי".

לפני השחזור מוצג מה הגיבוי מכיל, כולל מספר הפריטים בקטלוג.
אם מופיע "הגיבוי אינו כולל קטלוג פריטים" — הקטלוג לא היה טעון
במכשיר שממנו גיבית. טען אותו שם וגבה מחדש.

השאלה על הגדרות הסנכרון: **ענה "ביטול"** אם אתה רק מעביר נתונים
ורוצה שהמכשיר יישאר בחדר הסנכרון שלו.
