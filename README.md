# מדבקות — אפקון טכנולוגיות · גרסה 5.9

## התקנה
העלה את **שלושת הקבצים לשורש המאגר**, זה לצד זה:

```
avieotok/tavit/
├── index.html
├── sw.js
└── manifest.webmanifest
```

`sw.js` חייב לשבת בשורש. בתיקיית משנה מצב האופליין לא יעבוד.

## אחרי כל העלאה
1. המתן דקה עד שתיים לפרסום GitHub Pages.
2. בדפדפן: `Cmd+Shift+R` (רענון קשיח).
3. ודא שבכותרת מופיעה הגרסה הנכונה.

## בעדכון גרסה עתידי
עדכן את מספר הגרסה בשורה הראשונה של `sw.js`:

```js
const CACHE = 'afkon-labels-v5.9';
```

בלי זה הדפדפן ימשיך להגיש את הגרסה השמורה במטמון.

- **אייפון:** ספארי ← כפתור שיתוף ← "הוסף למסך הבית"

## סנכרון בין מכשירים
לחץ על כפתור הענן ← הזן קוד סנכרון זהה בכל המכשירים ← "התחבר וסנכרן".
מסונכרנים: תוכן הטפסים תוך כדי הקלדה, קטלוג הפריטים, ההיסטוריה,
תבניות העיצוב, פריסת הגיליון והכיולים.
